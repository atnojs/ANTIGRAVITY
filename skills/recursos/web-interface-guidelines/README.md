instrucciones de una URL cada vez es superficie de inyección y cambia el criterio sin avisar).

- **Origen:** <https://github.com/vercel-labs/web-interface-guidelines>
- **Fichero descargado:** `command.md` (reglas + formato de salida para agentes)
- **Fecha de fijado:** 2026-10-17
- **Copia local:** `2026-10-17_command.md`
- **Uso:** sección H de `skills/SKILL_AUDITOR.md` (`auditor-lighthouse-accesibilidad`).
- **Actualizar:** descargar de nuevo `command.md`, guardarlo como
  `<AAAA-MM-DD>_command.md`, actualizar esta ficha y revisar la sección H del auditor.
  No se actualiza a ciegas: los cambios de criterio se leen antes de aplicarlos.
