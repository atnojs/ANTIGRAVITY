# Manual de usuario

## Para crear un prompt desde una idea

1. Deja seleccionado **Modo automático** o elige **Crear desde cero**.
2. Escribe con palabras normales qué quieres conseguir.
3. Indica dónde vas a utilizar el prompt si lo sabes.
4. Pulsa **Crear prompt premium**.
5. Copia el resultado y pégalo en tu herramienta de inteligencia artificial.

## Para mejorar un prompt existente

1. Selecciona **Mejorar un prompt**.
2. Pega el prompt completo en el cuadro principal.
3. Añade en “Qué debe respetar o evitar” los nombres, marcas, formatos o elementos que no pueden cambiarse.
4. Pulsa **Crear prompt premium**.
5. Revisa las pestañas Prompt final, Mejoras, Supuestos y Validación.

## Cuándo usar cada calidad

- **Automática:** opción recomendada. La app elige un modelo adecuado.
- **Equilibrada:** menor coste y buena calidad para tareas habituales.
- **Máxima calidad:** para encargos complejos; puede consumir más créditos.

## Historial

Cada navegador conserva su propio historial anónimo en el servidor. Puedes buscar, abrir, editar, descargar o eliminar prompts. Borrar las cookies del navegador puede impedir recuperar ese historial.

## Privacidad

La clave de OpenRouter no se guarda en el navegador. Los textos que envíes se procesan mediante el modelo seleccionado en OpenRouter, por lo que no debes incluir contraseñas, claves privadas ni información especialmente sensible.
